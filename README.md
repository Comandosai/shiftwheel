# ShiftWheel

Бесплатный локальный конвертер файлов для macOS (Apple Silicon) и Windows 10/11 (x64). Начинаете тащить файл, жмёте **Shift**, и вокруг курсора открывается круглое меню. Отпускаете файл на нужный сектор, и рядом с оригиналом появляется результат. Оригинал не меняется, в интернет ничего не уходит.

Меню в светлом дизайне **Comandos Light**: кремовые секторы, сектор под курсором подсвечивается лаймом. Старое «жидкое стекло» включается так: `SHIFTWHEEL_THEME=glass`. Готовые сборки лежат на странице **Releases**.

Это форк [DragShift](https://github.com/llamaboi55/DragShift) (MIT). Мы добавили видео и звук через ffmpeg. Лицензия и авторство — в `LICENSE` и `NOTICE.md`. Оригинальный README лежит в `README.upstream.md`.

## Что умеет

| Тип | Конвертация | Инструменты |
|---|---|---|
| Картинки (PNG, JPG, WEBP, HEIC, TIFF, AVIF, BMP, GIF, ICO) | в любой из этих форматов и в PDF; несколько картинок → один PDF | сжать, изменить размер, обрезать, правка цвета, пометки, замазать, фон, метаданные/GPS |
| PDF | JPG, PNG, DOCX, TXT | сжать, разбить, повернуть, склеить, пароль, извлечь картинки, метаданные |
| DOCX / TXT / MD / HTML | PDF, TXT, DOCX | — |
| **Видео** (MP4, MOV, M4V, WEBM, MKV, AVI) | MP4, MOV, WEBM, GIF, MP3, M4A, WAV | **Compress** (H.264 до 1080p), **Small** (720p, минимальный размер), **Audio** (извлечь звук в M4A), **Join** (склеить несколько файлов) |
| **Звук** (MP3, WAV, M4A, AAC, FLAC, OGG, OPUS, AIFF) | MP3, M4A, WAV | **Join** |

Для видео и звука нужен ffmpeg:

```bash
brew install ffmpeg
```

Если ffmpeg не найден, приложение так и скажет. Порядок поиска: `$SHIFTWHEEL_FFMPEG`, затем бинарник внутри .app, затем `/opt/homebrew/bin`, затем `/usr/local/bin`, затем `$PATH`.

## Установка на Mac (сборка без подписи Apple)

1. Скачайте `ShiftWheel-arm64.dmg` из артефактов GitHub Actions: вкладка **Actions** → последний запуск *Build macOS app* → **Artifacts**.
2. Откройте .dmg и перетащите **ShiftWheel** в «Программы».
3. Снимите карантин, потому что приложение не подписано сертификатом Apple:
   ```bash
   xattr -cr /Applications/ShiftWheel.app
   ```
   Другой способ: правый клик → **Открыть**. На macOS 15 и новее это не срабатывает, тогда идите в **Системные настройки → Конфиденциальность и безопасность → «Всё равно открыть»**.
4. **Универсальный доступ (Accessibility) по коду не требуется.** Shift и кнопка мыши читаются через `NSEvent` без особых разрешений. Если меню по Shift всё же не появляется, добавьте ShiftWheel в **Системные настройки → Конфиденциальность и безопасность → Универсальный доступ** и перезапустите приложение.
5. Если нужно: **Запись экрана**. Это только для эффекта стекла, который «преломляет» окна позади меню. Без этого разрешения в меню просто виден фон рабочего стола.

ShiftWheel живёт в строке меню, иконки в Dock у него нет. Ещё есть правый клик по файлу → **Открыть в программе → ShiftWheel**.

## Установка на Windows

1. Скачайте `ShiftWheel-windows-x64.zip` из артефактов GitHub Actions: **Actions** → последний зелёный запуск → **Artifacts** → `ShiftWheel-windows-x64`.
2. Распакуйте архив в любую папку, например `%LOCALAPPDATA%\Programs\ShiftWheel`, и запустите `ShiftWheel.exe`.
3. Приложение не подписано, поэтому при первом запуске может появиться SmartScreen («Windows защитила ваш компьютер»). Нажмите **Подробнее → Выполнить в любом случае**.
4. Поставьте ffmpeg для видео и звука:
   ```powershell
   winget install Gyan.FFmpeg
   ```
   Подойдут и `choco install ffmpeg` или `scoop install ffmpeg`. ShiftWheel сам найдёт ffmpeg в `%SHIFTWHEEL_FFMPEG%`, в папке приложения (`ffmpeg\ffmpeg.exe`), в папках winget, Chocolatey и Scoop, а также в `PATH`.
5. ShiftWheel живёт в области уведомлений рядом с часами. Работает так же, как на Mac: начинаете тащить файл, жмёте **Shift**, отпускаете файл на нужный сектор. Специальных разрешений не нужно.

## Сборка самостоятельно

```bash
python3 -m venv .venv && . .venv/bin/activate
pip install -r requirements.txt pyinstaller pytest
python scripts/restore_assets.py          # иконки хранятся в репо как base64
python -m pytest -q
pyinstaller ShiftWheel.spec --noconfirm   # → dist/ShiftWheel.app
```

## Ограничения

- Приложение не подписано и не нотаризовано Apple, поэтому при первом запуске будет предупреждение (см. выше).
- ffmpeg в приложение не встроен: его нужно поставить через Homebrew на Mac или winget на Windows. Почему так, см. `NOTICE.md`: лицензия GPL у brew-сборки.
- **Join** склеивает без перекодирования, поэтому у файлов должны совпадать кодек, разрешение и частота. Иначе ffmpeg выдаст ошибку.
- Обрезка видео по времени (`media.trim`) есть в коде, но в меню пока не выведена, потому что ей нужно окно выбора интервала.
- Прогресса для длинных видео нет: идёт индикатор «Compressing…», а потом приходит уведомление.
- Конвертация в GIF ограничена 12 кадрами в секунду и шириной до 640 px, иначе файл получается огромным.
- Сборки: macOS Apple Silicon (macos-14) и Windows x64 (windows-latest). Intel Mac и Windows ARM отдельно не собираются.
- Для Windows пока есть только zip: установщика, пункта в меню «Пуск» и пункта в контекстном меню Проводника нет. Скрипт установщика `installer/ShiftWheel.iss` (Inno Setup) лежит в репо, но в CI не собирается.
- Exe не подписан, поэтому SmartScreen и антивирусы могут ругаться.
